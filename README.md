## 📖 블로그 소개 및 이용 방법

### 🌌 블로그 소개
**MathAstro**는 수학(Math)과 천문/물리(Astro)를 중점으로 다양한 주제들을 다루는 Quarto 기반의 블로그이며, 현재 두 명의 운영진이 공동으로 운영하고 있습니다. 더욱 다양한 분야의 전공자들과 함께 블로그를 만들어나가고 싶습니다. 관심 있으신 분들은 운영자들의 이메일로 연락주세요.

### 🛠️ 이용 방법
각 학문 분야별로 세부 주제들이 분류되어 있습니다. 예를 들어 수학에서 추상대수학(Abstract Algebra)의 경우 Group Theory, Field Theory, Ring Theory 등으로 나뉘어 있습니다. 포스트를 읽다가 궁금한 점이 생기면 상단의 Q&A 게시판을 통해서 작성자에게 직접 질문할 수 있습니다.
